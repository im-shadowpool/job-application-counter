# Job application counter

A small React + TypeScript + Material UI counter that stores everything in this browser.

## Run locally

Run npm install, then npm run dev.

The seven-day strip runs from oldest to newest. Switch to the month view to browse older dates. Counts are kept in localStorage and are not automatically removed. Notes are saved as separate messages; edit or delete them from the Notes drawer. Notes are never removed automatically. Theme preference is also saved locally.

Tap the counter to add one. Right-click it on desktop to subtract one. Undo restores the previous count change.
